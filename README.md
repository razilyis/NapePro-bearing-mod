# Keychron NapePro Bearing Mod 🖱️⚙️

Keychron NapePro のトラックボール受けを、ベアリング支持（ミニチュアベアリング ＋ 並行ピン）に変更するためのケース改変データ（3Dプリント用）です。  
摩擦を極限まで減らし、より滑らかなボール操作感を実現することを目的としています。

---

## 🛠️ 必要部品 / Required Hardware

組み立てには、プリント出力したケース本体のほか、以下のパーツが別途必要です。

| パーツ名 | 仕様・サイズ | 数量 | 備考 / 入手先例 |
| :--- | :--- | :--- | :--- |
| **ミニチュアベアリング** | 内径 1.5mm × 外径 4mm × 幅 2mm | 3個 | 例: 681XZZ (両シールド付き深溝玉軸受 / uxcell等) |
| **並行ピン（軸）** | 直径 φ1.5mm × 長さ 4mm | 3本 | 例: モノタロウ・ミスミ等 |
| **トラックボール** | **25mm** （純正または互換品） | 1個 | NapePro標準のボール |
